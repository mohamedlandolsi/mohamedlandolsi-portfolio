# OG card fonts

Static TTF cuts of the site's fonts, read at build time by `lib/og.tsx` (next/og cannot read the woff2 files next/font serves). Not deployed as web fonts.

- `SpaceGrotesk-Bold.ttf`: Space Grotesk 700
- `IBMPlexSans-Regular.ttf`: IBM Plex Sans 400
- `IBMPlexMono-Regular.ttf`: IBM Plex Mono 400

All three are from Google Fonts and licensed under the SIL Open Font License 1.1.
