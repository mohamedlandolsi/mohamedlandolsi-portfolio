# Anti-patterns: what makes a site look generated

Check every page against this list before calling it done. Each item is a default that templates and AI tools reach for regardless of subject. If one appears, remove it or justify it in one sentence tied to the brief.

## Layout and components

- Content chopped into identical rounded cards with one radius, one soft grey shadow and a hover lift.
- A bento grid of feature tiles.
- A centered hero with a gradient blob, an avatar and two pill buttons.
- A "tech stack" wall of logo icons.
- Section after section with the same structure (heading, paragraph, three cards).
- Glassmorphism, blurred backdrops, glowing borders.
- A dark navy page with a single neon accent.
- A newspaper layout with hairline rules everywhere and dense columns.
- shadcn/ui defaults (zinc greys, 0.5rem radius, the same button and badge), Lucide icons next to every heading.

## Type and copy chrome

- Tracked-out ALL-CAPS labels above headings ("ABOUT ME", "SELECTED WORK").
- Numbered section markers (01, 02, 03) on content that is not a sequence.
- One word in a headline set in italic, a gradient or a different color.
- Meta strings joined with middle dots ("2026 · n8n · Clay").
- Labels built with a spaced long dash between two words (Role, long dash, Engineer).
- A "→" appended to every link and button.
- Monospace for small labels to look technical.
- Typewriter effects, rotating job titles, "Hi, I'm Mohamed 👋".
- Words: passionate, seamless, cutting-edge, leverage, unlock, empower, journey, innovative, robust (unless it is a measured claim), "I'm a ... who loves ...".

## Motion

- Fade-and-slide-up on every section as it scrolls into view.
- Hover transitions on every card and image.
- Parallax, cursor followers, magnetic buttons, marquee tickers of tools.
- Animated counters on every number. (The sieve counts are the only counters on the site.)

## Color

- A warm cream background with a serif display face and a terracotta accent.
- Purple to blue gradients. Any gradient.
- Black text. On this site, text is ink blue.
- Sunflower used as decoration rather than for a human action or decision.

## Content

- Numbers without a source or date. Rounded or inflated numbers ("90%+", "thousands").
- Skills bars and percentages ("Python 90%").
- Testimonials that are not real and attributed.
- Screenshots containing other companies' data or names of real prospects.

## Self-check questions

1. If I swap the name and the content, would this page work for any developer? If yes, it is a template. Make the content do the design.
2. Where is the one bold thing on this page? If there are two, quiet one.
3. Remove one accessory. What did I remove?
